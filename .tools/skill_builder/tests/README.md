# Проверки скилла RulewayUML

Каталог хранит воспроизводимые проверки и компактные результаты. Сырые каталоги запусков, экспортированные SVG/PNG/HTML и статические просмотрщики в репозиторий не добавляются.

## Состав

- `check.py` — полный контейнерный тест сборки, экспорта девяти схем, переносимости и отказов без частичного результата.
- `check_export_contract.py` — проверка интерфейса экспортёра с подставленным ответом PlantUML.
- `evals/evals.json` — поведенческие задания и проверяемые ожидания.
- `evals/files/` — предоставленные пользователем исходные материалы, необходимые для повторения задания.
- `results/` — краткие отчёты и агрегированные наблюдения без копий экспортированных комплектов.

Пути в поле `files` файла `evals/evals.json` задаются относительно каталога `.tools/skill_builder/`. Поэтому локальные фикстуры начинаются с `tests/evals/files/`, а публичные примеры проекта доступны через `../../examples/`.

Рабочие результаты поведенческих прогонов размещай во временном каталоге либо в игнорируемых `.tools/rulewayuml*-workspace/`. После фиксации итогов удаляй их. Нужные для повторения сведения должны оставаться в `evals/`, `results/` и контексте задачи.

Готовый устанавливаемый пакет хранится отдельно в `dist/rulewayuml-0.0.1.zip` и включается в репозиторий. Распакованный пакет в рабочем дереве не оставляй.
