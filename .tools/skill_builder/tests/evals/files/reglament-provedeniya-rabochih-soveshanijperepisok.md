## Основные положения

1. &[Каждое рабочее совещание](695144) должно быть создано с описанной **повестки** и приложено в описании встречи. При наличии приложены документы для обсуждения;
2. Описанная и подготовленная повестка совещания должна служить основным источником для формирования рассмотренных вопросов. При необходимости вкладывания дополнительных материалов, в повестке (протоколе) они должны быть обозначены как ссылки на приложение с наименованием документа. Прикладываемые документы должны быть, также приложены к повестке встречи;
3. Итогом совещания должны быть сформулированные решения по каждому поднятому вопросу. Любое решение должно быть описано с фамилией и организацией ответственного за выполнение и проставленной датой окончания выполнения;
4. По итогам совещания формируется протокол, в который заносятся формулировки всех перечисленных выше пунктов. Составлением протокола занимается  **ведущий** совещания. Также, в протокол заносится полная повестка совещания с ссылками на приложения при необходимости;
5. Составленный, по результатам встречи, протокол должен быть **обязательно** направлен на согласование всем согласующим, определенным участниками совещания. Согласование может проходить через **почту** или систему согласования **Лотус**. Второй вариант при его осуществимости, всегда превалирует над первым;
6. После согласования протокола, он должен быть сохранен в организованный архив **Менеджером продукта** той команды, интересы которой обсуждались на совещании. Протокол, также должен использоваться в виде прикрепленного документа к **задаче, стори, эпику**, которые возникли по итогам принятых решений; Если принятые в протоколе решения находятся уже в работе, то протокол должен быть также прикреплен к **задаче, стори, эпику** с указанием конкретного сценария реализации.
