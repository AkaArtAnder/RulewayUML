# Выбор образца

Все образцы учебные: заимствуй конструкцию и правила заполнения, а не роли, сроки, ссылки или исходы. Владелец библиотеки подтвердил корректное отображение исходных схем. Это не подтверждает их работу в любом редакторе или Яндекс Wiki.

| Потребность | Образец |
| --- | --- |
| Последовательность, проверка и доработка | [Основной процесс без дорожек](../assets/examples/basic_regulation_no_lanes.puml) |
| Тот же процесс с дорожками | [Основной процесс](../assets/examples/basic_regulation.puml) |
| Раскрытие проверки в отдельной схеме | [Проверка заявки](../assets/examples/review_regulation.puml) |
| Два независимых результата до продолжения | [Параллельная подготовка](../assets/examples/parallel_results.puml) |
| Ответ или наступление известного срока | [Ожидание ответа](../assets/examples/external_response.puml) |
| Основание отсутствует и должно быть получено | [Получение заключения](../assets/examples/missing_basis.puml) |
| Различение замечаний и невозможности проверки | [Основной процесс](../assets/examples/subregulation_result.puml) и [дочерний](../assets/examples/subregulation_review.puml) |

Подробные предпосылки, ожидаемые пути и сроки четырёх сложных образцов — в [описании маршрутов](route_details.md). Читай нужный раздел при применении соответствующего образца.

Все файлы в `assets/examples/` подключают `../components/`. При переносе в пользовательский каталог поправь только пути подключений в новой копии. Относительные адреса ссылок рассчитаны на соседние SVG и каталог `materials/`. Для существующего регламента сохраняй его адреса.
