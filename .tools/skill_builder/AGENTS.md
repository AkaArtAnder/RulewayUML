# Разработка пакета RulewayUML

Этот каталог содержит материалы для разработки и сборки скилла. Работай здесь при изменении самого скилла, его упаковки или проверок.

- `source/skill_template.md` — текст будущего `SKILL.md`; рассматривай его и справочники как исходные данные создаваемого продукта. Не подключай их как навык для обычной работы над библиотекой.
- `source/references/` и `source/scripts/` входят в устанавливаемый пакет. Экспортёр запускай из временно собранного пакета с его ресурсами.
- `build.py` собирает пакет; `tests/` хранит проверки, поведенческие задания и компактные результаты; `scenarios/` содержит учебные схемы; `specification.md` описывает требования.
- Библиотека берётся из корневого `components/`, общие примеры — из `examples/`, окружение — из `.devcontainer/Dockerfile`. Здесь их исходные копии не создаются.
- Распакованный пакет и сырые результаты проверок размещай в `/tmp` либо в игнорируемых workspace-каталогах и удаляй после фиксации итогов. В `dist/` хранится и включается в репозиторий только готовый ZIP; `SKILL.md` внутри него предназначен для установки пользователем. Не оставляй распакованные скиллы в дереве проекта.
- Публичная версия пакета имеет числовой формат `X.Y.Z` без суффиксов вроде `-dev`; первая публикуемая версия — `0.0.1`.
- Сборка и проверки выполняются только в Docker. При этой реорганизации разрешены проверки файлов и интерфейса с подставленным ответом движка; рендеринг ранее принятых схем не запускать.

Из корня репозитория, при отсутствии одноимённого ZIP в `dist/`:

```sh
docker run --rm --network none --user "$(id -u):$(id -g)" \
  --mount "type=bind,src=$PWD,dst=/workspace,readonly" \
  --mount "type=bind,src=$PWD/dist,dst=/output" \
  --entrypoint python3 rulewayuml-dev:plantuml-1.2025.10 \
  /workspace/.tools/skill_builder/build.py /output
```

Сборщик создаёт стандартный `SKILL.md` из шаблона, добавляет ресурсы и удаляет временный каталог после упаковки. Существующий ZIP не перезаписывается; для проверки новой редакции сначала собери её в отдельный временный каталог, проверь пакет, затем замени версионный ZIP в `dist/`. Архив в `dist/` является публикуемым артефактом репозитория, но не вторым источником компонентов.
