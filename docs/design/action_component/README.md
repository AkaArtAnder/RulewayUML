## Что сравниваем

Три самостоятельных макета PlantUML показывают одинаковые семь параметров: идентификатор, название, ответственную роль, результат со ссылкой на шаблон, инструкцию/чек-лист, срок/SLA и ссылку на дочерний регламент. В каждом варианте используются одни учебные данные из [action_design_content.iuml](action_design_content.iuml). Это данные макетов и локальные настройки оформления, не API компонента.

Все варианты подключают существующий `components/style.puml`. Светлый фон, белые блоки, тёмно-синий текст, бирюзовые контуры и ссылки, DejaVu Sans и отдельный фирменный знак сохранены. При подготовке макетов общий стиль библиотеки не менялся; на этапе 3 выбранные выравнивание по левому краю и `MaximumWidth 330` перенесены в общий стиль. В макетах локально заданы выравнивание по левому краю и `MaximumWidth 330`; у бокового примечания — `MaximumWidth 280`. Настройка примечания относится только к варианту В.

Ссылки подчеркнуты и имеют понятные названия. Чек-лист показан текстовым перечнем: фактические отметки исполнения не предполагаются. Содержание читается целиком без раскрывающихся секций и наведения.

## Варианты

| Вариант | Устройство | Преимущество | Ограничение |
| --- | --- | --- | --- |
| **А — компактный блок** | Идентификатор и название в одной строке; ответственный и срок рядом с подписями; результат и инструкция отделены отступами | Меньше высота, подходит для кратких действий | При длинном названии идентификатор и заголовок образуют общий многострочный текст; границы разделов выражены слабее |
| **Б — карточка с разделами** | Отдельный заголовок с идентификатором; роль и срок; результат; инструкция; ссылка на дочерний процесс. Разделы отделены тонкими линиями | Все сведения внутри блока; разделы легко найти и сопоставить между действиями | Немного больше высота; длинная инструкция всё равно увеличивает карточку |
| **В — инструкция рядом** | Основные сведения в блоке действия; инструкция в связанном примечании справа | Основной маршрут короче по вертикали; инструкция явно отделена | Схема становится шире; примечание использует меньший шрифт общего стиля, размещение рядом с дорожками потребует отдельной проверки |

Исходники: [А — compact.puml](compact.puml), [Б — sections.puml](sections.puml), [В — side_note.puml](side_note.puml).

**Выбор владельца от 2026-09-22 — А, компактный блок.** По его замечанию подпись «Роль» заменена на «Ответственный». Значение по-прежнему описывает ответственную роль. Варианты Б и В сохранены для истории сравнения. После этой правки владелец утвердил дизайн А и явно разрешил этап 3.

## Проверенные состояния

1. Обычное действие «Проверить заявку», роль «Согласующий», три пункта инструкции, текст результата со ссылкой, срок и подрегламент.
2. Длинное название, длинная роль, развёрнутый срок и результат, четыре длинных пункта инструкции.
3. Обычное действие без дочернего регламента: ссылка и относящийся к ней разделитель/отступ убираются.

## Воспроизведение

Из корня репозитория, с уже собранным образом проекта:

```bash
docker run --name ruleway-action-design-review --network none --user vscode \
  --mount "type=bind,source=$PWD,target=/workspace,readonly" \
  --workdir /workspace rulewayuml-dev:plantuml-1.2026.5 bash -lc '
    set -e
    plantuml -charset UTF-8 -checkonly docs/design/action_component/*.puml
    for format in svg png; do
      plantuml -charset UTF-8 -failfast2 -t"$format" \
        -o /tmp/ruleway-action-design/standard docs/design/action_component/*.puml
      plantuml -charset UTF-8 -failfast2 -Druleway_design_long -t"$format" \
        -o /tmp/ruleway-action-design/long docs/design/action_component/*.puml
      plantuml -charset UTF-8 -failfast2 -Druleway_design_no_subreg -t"$format" \
        -o /tmp/ruleway-action-design/no_subreg docs/design/action_component/*.puml
    done
  '
mkdir -p /tmp/ruleway-action-design-preview
docker cp ruleway-action-design-review:/tmp/ruleway-action-design/. \
  /tmp/ruleway-action-design-preview/
docker rm ruleway-action-design-review
```

Флаги проверены на установленной версии; команды выполнены с тем же содержимым под именем контейнера `ruleway-action-design-v2-20260922`. Переключатели `ruleway_design_long` и `ruleway_design_no_subreg` существуют только для сравнения макетов, не являются параметрами будущего компонента.
