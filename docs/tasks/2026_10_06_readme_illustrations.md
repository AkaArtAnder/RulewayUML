## Решения и ограничения

- Иллюстрации экспортированы в PNG штатным PlantUML `1.2025.10` в существующем Docker-образе, без изменения исходников и установки зависимостей на хост. Постоянные материалы README хранятся в `docs/images/`; временные результаты — в `/tmp`.
- Новое поручение создать иллюстрации подразумевает необходимый экспорт выбранных схем. Прежние ограничения проверок относились к уже принятым задачам перехода окружения и компонентов; полный тестовый контур в этой задаче не запускается.
- Каждая иллюстрация сопровождается пояснением и ссылками на исходник и полноразмерное изображение. PNG иллюстрирует внешний вид; переходы внутри картинки не интерактивны.
- Предлагаемые критерии готовности: изображения соответствуют текущим исходникам, ссылки существуют, README читается в двух темах и на узком экране. Приёмка результата — пользователем.
