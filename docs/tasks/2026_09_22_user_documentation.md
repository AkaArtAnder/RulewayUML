## Цель и основание

По замечанию владельца описание действия перегружено выводами этапов разработки. Требуется выделить пользовательскую документацию в `docs/specification/`, разместить руководство по первому компоненту в `docs/specification/components/` и дать общее описание библиотеки. В руководствах остаются назначение, возможности, правила применения и примеры.

## Исходное состояние и границы

- Прочитаны README, общий контекст, AGENTS.md, руководство действия и контекст его разработки; описание сверено с процедурой, примерами и конфигурацией окружения.
- Рабочее дерево содержит незакоммиченные изменения и новые файлы предыдущих задач. Они сохраняются; текущие правки касаются документации и ссылок на неё.
- В `docs/components/action.md` смешаны пользовательские инструкции, история предпросмотра, измерения схем и результаты проверок. История и результаты уже зафиксированы в общем контексте и задаче компонента.
- API, оформление, исходники примеров и окружение не требуют изменений. Приёмка этапа 3 компонента остаётся открытой.

## Решения и результат

- Создано [общее руководство](../specification/README.md): назначение библиотеки, доступные возможности, подключение, правила построения регламентов, предпросмотр, экспорт и ссылки на примеры.
- [Описание действия](../specification/components/action.md) перенесено в `docs/specification/components/` и сокращено до назначения, сигнатуры и параметров, правил заполнения, двух примеров и поведения ссылок. Оба фрагмента PlantUML сохранены без изменений.
- Из пользовательского описания убраны история согласований и ошибки предпросмотра, сравнение размеров схем, отчёты о тестах и технические подробности оформления. Эти сведения сохранены в документах разработки; общие инструкции использования вынесены в руководство библиотеки.
- Обновлены ссылки в README, AGENTS.md, общем контексте, ТЗ, описании макетов, контексте действия и комментарии `components/action.puml`. Старый файл и опустевший `docs/components/` удалены.
- В AGENTS.md закреплено разделение пользовательских руководств и истории разработки; структура и решение отражены в общем контексте. Приёмка этапа 3 компонента остаётся открытой.

## Проверки и ограничения

- Проверены локальные ссылки и якоря Markdown, пути ресурсов README и фактическая структура документации; битых ссылок не обнаружено.
- Сигнатура и обязательность полей сверены с реализацией. Версия PlantUML `1.2026.5` совпадает с `ARG PLANTUML_VERSION` в Dockerfile.
- Сравнение с копиями файлов на начало задачи подтвердило: оба примера в руководстве прежние, в компоненте изменён только комментарий; ТЗ и материалы дизайна менялись только для обновления ссылок.
- `git diff --check` пройден; новые руководства дополнительно проверены на пробелы в конце строк. Оформление корневого README сохранено.
- Рендеринг, браузерная навигация и визуальный предпросмотр повторно не запускались: изменены текст документации и пути к ней. Проверки предыдущих этапов не выдаются за новые.

Обязательной оставшейся работы по организации документации нет. Незакоммиченные изменения предыдущих задач сохранены.
