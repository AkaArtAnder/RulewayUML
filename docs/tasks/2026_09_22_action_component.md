Создать и описать компонент действия с полным набором необходимых параметров для представления конкретного процесса внутри регламента.

1. Прочитать исходную статью AFFiNE, представить параметры для совместного редактирования и согласования, сформировать ТЗ в Markdown.

3. После согласования завершения этапа 2 реализовать компонент, обновить тестовый пользовательский пример и проверить применимость по требованиям.
